# Expansion board (KiCad 9)

The adapter board for the expansion build: the Tang Nano 20K plugged into a real
Jupiter Ace's edge connector, with the 3.3 V / 5 V bus buffers. KiCad project,
schematic, PCB (footprints placed, outline and design rules set, routed by hand) and
the BoM generated from the schematic.

Not drawn yet.
