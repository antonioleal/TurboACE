# TurboACE ROM source

Builds the 64K TurboACE ROM (8 × 8K pages) described in `../register-map.md` §5.

## Requirements

- **sjasmplus** 1.20.3, built in `../tools/sjasmplus/` (`make -C ../tools/sjasmplus`);
  the Makefile uses `../tools/sjasmplus/sjasmplus` by default. Pass `ASM=...` to use another one.
- **python3**.
- **The stock Jupiter Ace ROM image**, 8192 bytes, SHA-1
  `597ba8a15a292688333c84dc9fd35172abe5e7e6`. It is not included. The Makefile
  refuses any other image.

## Build

```
make ACE_ROM=/path/to/ace.rom          # build/turboace.rom + build/page0..7.bin
make check ACE_ROM=/path/to/ace.rom    # static checks (tools/misc/romcheck.py)
make equates ACE_ROM=/path/to/ace.rom  # regenerate inc/ace_words.inc
make flash ACE_ROM=/path/to/ace.rom    # build/turboace-flash.bin: pages 2-7 for the board's flash
```

The board never stores the stock ROM: the soft CPU's firmware reads `/ace.rom` from the SD
card at power-up and makes pages 0 and 1 from it. The flash image leaves out each page's
copy of the stock interrupt path, which the firmware fills in from `/ace.rom`
(`../register-map.md` §2.7). Write it with `make -C .. program-rom ACE_ROM=/path/to/ace.rom` (openFPGALoader).

## Layout

| File | Contents |
|---|---|
| `turboace.asm` | page assembly: page 0 stock, page 1 hook, page 2 boot, pages 3–7 |
| `inc/hw.inc` | ports, `$E3` commands, extended registers, AY, memory map, state |
| `inc/ace_internal.inc` | stock ROM internals (not words), each checked against the ROM |
| `inc/ace_words.inc` | stock word code-field addresses (generated by `tools/misc/acedict.py`) |
| `src/lowcopy.asm` | `LOWCOPY` macro: interrupt path + RST copy for pages 2–7 |
| `src/xdict.asm` | extension dictionary, assembled for `$3000`, copied to RAM at boot |
| `src/boot.asm` | boot page setup |
| `src/sdpage.asm` | ROM page 3, the SD page: tape-hook entries, exits and handlers (cassette and SD paths), SD protocol helpers |
| `src/mathpage.asm` | ROM page 4, maths: `RND`, the `FSQRT` first guess |
| `src/gfx.asm` | graphics routines: `HPLOT` `HDRAW` `HCIRCLE` `HPOINT` `HATTR` `HCLS` `HPAINT` |

## Status

Every mechanism is present: the boot hook, the copy ranges, the dispatcher,
colon words, code words, constants, dispatched routines and superset words.

- **Words:** `TURBO` `COUNT` `+!` `?` `DEPTH` `HEX` `CMOVE` `FILL` `PLAY!` `PLAY@`
  `INK` `PAPER` `BORDER` `DARK` and the colour constants, `MODE` `PG0` `PG1`
  `FONT` `VIEW` `WORK` `SCREEN`, and the graphics words
  `PLOT` `DRAW` `CIRCLE` `POINT` `INVERSE` `FLIP` `CLS` `ATTR` `PAINT` `OPAQUE`, and
  the SD words `SDTAPE` `TAPE` `EJECT` `DIR` `CD` `DELETE` `PGSAVE` `PGLOAD` `SCRSAVE` `SCRLOAD` `FONTLOAD` `SDERR`.
- **Word addresses are not yet frozen.** Freeze them at the first release.
- **Assembles** with sjasmplus 1.20.3 with no errors or warnings, and `make check` passes.
- **The programming words** (`.S` `'` `2*` `2/` `0<>` `CASE` `OF` `ENDOF` `ENDCASE` `RND` `RAND` `GR` and the double-cell words) **are tested by typing them into the real ROM** in `../test`: the whole machine from reset with the 50 Hz interrupt, keys through the firmware's PS/2 translation, results read off the screen, including `LIST` of a `CASE` word.
- **The tape hooks (cassette path: equal to the stock ROM register for register and edge for edge, plus a loopback read; SD path: against a model of the soft CPU's tape player), `SDTAPE`/`TAPE`/`EJECT`/`DIR`/`CD`/`DELETE`/`PGSAVE`/`PGLOAD`/`SCRSAVE`/`SCRLOAD`/`FONTLOAD`/`SDERR`, the boot page, `TURBO` (all four modes, and the card in `-1 TURBO` through a Forth session with the real SD firmware), `OPAQUE`, `PG0`/`PG1`, `SCREEN`/`WORK`/`VIEW`, `CLS`, `DRAW` (lines and arcs), `CIRCLE`, `PAINT` and hi-res `ATTR` are tested** by `../test` (`make -C ../test`): the built
  ROM runs on the Jupiter-IIb Z80 core and the results are compared with
  reference models (12,448 checks, including an end-to-end run of the SD words and tape hooks against the real firmware in `../firmware` on a FAT RAM disk). The other words have not been executed;
  running them in a full machine needs the Jupiter-IIb emulator changes.
